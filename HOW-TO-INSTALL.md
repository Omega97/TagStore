# How to install TagStore

TagStore puts tags on the pictures in a folder on your computer. The tags are the words in the path of every file. Your pictures stay on your computer.

You need Windows. You do not need to install anything else first.

## 1. Download the installer

Open the download page you were given. It is a normal web page.

Download the file whose name looks like this:

`TagStore-Setup-0.1.0.exe`

The numbers at the end may be newer. Pick the file that starts with `TagStore-Setup` and ends with `.exe`.

Leave the other files alone. You only need this one.

## 2. If Windows warns you

Open the file you downloaded.

Windows may say that it protected your PC. That appears because TagStore does not have a paid Windows signature yet.

Click **More info**, then **Run anyway**.

## 3. Install

Follow the windows on screen.

- You should not be asked for an administrator password.
- Leave **Create a Desktop shortcut** ticked if you want an icon on the desktop.
- Click **Install**, then **Finish**.

## 4. First time you open it

Open **TagStore** from the desktop icon, or from the Start menu.

A window asks you to choose a folder. Pick the folder that contains your pictures.

TagStore remembers that folder. The next time you open the app, it uses the same one.

Open the menu in the app and click **Scan database**. Your pictures show up, with tags taken from their file names.

## Remove TagStore

Open Windows **Settings**, then **Apps**. Find **TagStore** and uninstall it.

Your pictures stay where they are, and the tags saved next to them stay too.
